Connect this device

You only do this once on each phone or computer. The access key stays on this device.

How to get an access key
  1. Sign in to GitHub as the website owner and open New fine-grained token.
  2. Name it OKSHOE admin and set an expiry date (for example 1 year).
  3. Under Repository access, choose Only select repositories and pick buckle-website.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it below.
